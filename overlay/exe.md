- **Concurrent sessions share this box.** Several agent sessions run at once, and a project checkout under `~/src` can have its branch switched or its tree edited by another session mid-task. Implement in a worktree under `<repo>/.worktrees/`, never by switching branches in the shared checkout. Treat unexplained `git status` entries as someone else's in-flight work: inspect, never discard. If a commit landed on their branch anyway, cherry-pick it onto yours in a worktree, then `git reset --keep <their-tip>` in the shared checkout.
- **Auto mode gates bulk destruction.** The permission classifier blocks batches of irreversible local operations (worktree removals, database drops) even after single ones succeeded; it tracks the accumulating pattern, and conversational consent never reaches it. Do the verification first so the destructive step is one shot, then either ask the operator for a scoped permission rule (via the `update-config` skill, with their explicit say-so, never self-granted) or hand them a ready-to-paste command block to run with the `!` prefix. Don't burn turns retrying.
- **Never assess your own PR's review risk.** `risk-audit` and `risk-sweep` are user-invoked only; the Skill tool refuses them. Don't post a review-map comment or set a risk label on a PR you authored. Caveats go in the PR body's Feedback section, and the operator can run `/risk-audit` if they want the label.
- **Box facts.** Two CPUs. The Workflow harness runs two agents concurrently here. Sessions started by systemd (the review watcher) get no profile, so `just` is at `~/.cargo/bin/just` there, off `PATH`. pnpm is not preinstalled and corepack is absent (`npm install -g pnpm`); pnpm 11 gates native build scripts behind a per-project `allowBuilds` in `pnpm-workspace.yaml`, and its global config is YAML at `~/.config/pnpm/config.yaml`, where `verifyDepsBeforeRun: false` stops `pnpm run` failing its pre-run check with `ERR_PNPM_IGNORED_BUILDS`.
- **When backgrounding a gate, propagate its exit code.** `just ci; echo EXIT=$?` makes the wrapper exit 0 and the completion notification reads green on a red run. Use `rc=$?; …; exit $rc`.
